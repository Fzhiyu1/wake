wake 知道你的 AI 2026

你读过的东西
在悄悄改你怎么想事情。

让你的 AI,也读到那些东西。

01

看不见的图书馆,一直在工作

你读完一本好书的几天里,看世界会带着这本书的滤镜。判断一件事,会下意识用书里的概念框一下。这不是"想起书里的句子"——是书悄悄改了你看东西的角度。

再过半年,这本书你大概忘了具体内容。但它对你思考的影响还在。这就是大脑里那座"看不见的图书馆"——它平常不出声,但你做任何判断时,它都在。

你不是在"调用"读过的东西,是被它们塑造着思考。
02

现在的 AI 缺这一块

ChatGPT、Claude 知道全世界的知识,但不知道你。你的笔记、你想过的事、你过去得出的结论——这些都在它的视野之外。

所以你问它一个问题,它给你的是"通用答案"——综合一万个人意见后的中位数,不是带着你的角度的回答。而且每次新对话你都得从头解释自己:我之前想过 A,我相信 B,我对 C 持保留态度……一会儿就累了。

问题不是 AI 不够聪明,是它不知道你怎么想事情。

03

看一下区别

同一个问题,问两种 AI——一个不知道你,一个读过你的笔记。差别看一下:

我应该接这个 offer 吗 今天工作不顺 周末怎么过 该不该跟这个朋友疏远
我应该接这个 offer 吗?
普通 AI
这是个重要决定,建议从这几方面考虑:薪资福利、发展空间、公司文化、工作生活平衡、通勤距离。可以列个 pros & cons 表帮助梳理。
读过你笔记的 AI
你之前写过——"重大决定的真问题不是值不值得,是失败了我能不能 ok"。

你也提过——"换工作的核心问题是,留下我会变成什么样的人,跳过去我会变成什么样的人"。

pros & cons 表答不了这两个问题。

左边是教科书答案,正确但跟你没什么关系。右边把你过去想过的东西**带回来**——它不是查找,是想起。

不查你的笔记,而是用你过去想过的东西,接着想。
04

这事怎么做到的

简单到反直觉:把你的笔记整个交给 AI,让它每次回答前都浏览一遍。

听起来像不可能——笔记几十万字怎么塞进 AI?但 2024 年起,长上下文 AI 出现(单次能读几百页),加上"读过一次缓存起来"的机制,让这件事变得便宜:**你的笔记从此每次对话都在场,但成本几乎为零**。

wake 是这个想法的开源实现。装上后,你的 Claude 每次回答前都会先浏览你的笔记,从你过去想过的东西里浮出跟当前问题有关的部分。你不用主动调用——它在背景里自己工作。

05

四行命令上手

git clone https://github.com/Fzhiyu1/wake.git && cd wake python3 -m venv .venv && .venv/bin/pip install openai cp .env.example .env # 填 DeepSeek API key,几分钱跑一天 .venv/bin/python3 daemon.py "我最近在想什么"

跑出来如果有几条"想起来的东西"(像随手翻你笔记浮上来的片段),而不是百科全书答案,就是工作的。

然后看 README 选一种装法——装到 Claude Code、Cursor、或任何用 Claude 的客户端上。装好后,你的 AI 就开始"读过你"了。

不是给 AI 加一个搜索框,是让它带着你的视角做事。
